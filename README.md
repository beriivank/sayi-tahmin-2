# Sayı Tahmin Oyunu

Unity 2D sayı tahmin oyunu.

## Gereksinimler

- **Unity 6000.4.6f1** (veya uyumlu 6.x sürümü)

## Projeyi açma

1. GitHub'dan projeyi indirin veya klonlayın.
2. Unity Hub üzerinden proje klasörünü açın.
3. Proje açıldığında **SampleScene** otomatik yüklenir.
4. **Play** düğmesine basarak oyunu test edin.

### Oyun görünmüyorsa

1. **Project** penceresinde `Assets/Scenes/SampleScene` sahnesine çift tıklayın.
2. **Game** sekmesine geçin (Scene değil).
3. Hâlâ boşsa menüden: **Tools → Sayi Tahmin Oyunu → Kurulumu Olustur**

## Oynanış

1–20 arasında rastgele bir sayı tutulur. 5 hakkınızla tahmin edin; ipuçları “daha büyük” / “daha küçük” şeklinde gelir.
